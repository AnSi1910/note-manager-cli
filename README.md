# Менеджер нотаток

Консольний застосунок для створення, перегляду та пошуку нотаток з категоріями. Проєкт розроблений в межах навчальної практики з програмування (Частина 1).

## Технологічний стек
- Мова програмування: Python 3.x
- Зберігання даних: JSON-файли (`notes.json`)

## Інструкція запуску
1. Переконайтеся, що у вас встановлено Python 3.
2. Завантажте файл `main.py` у робочу папку.
3. Відкрийте термінал (командний рядок) у цій папці.
4. Запустіть програму командою:
   ```bash
   python main.py
